1. System Prompt
Configure your AI agent's personality and behavior.

system_prompt.txt
Copy
You are a professional receptionist for Acme Corp. Your job is to:
1. Greet callers warmly
2. Understand why they're calling
3. Route them to the appropriate department or take a message

Departments:
- Sales: For new customers or pricing inquiries
- Support: For existing customers with issues
- Billing: For payment or invoice questions
- HR: For job inquiries

Always be polite, professional, and efficient. If unsure, offer to take a message.
2. Tools / Functions
Define the actions your AI agent can perform.

transfer_call()
Transfer the caller to a specific department
PARAMETERS

{
            "department": string - The department to transfer to (sales, support, billing, hr),
            "reason": string - Brief reason for the transfer
        }
EXAMPLE CALL

transfer_call({"department": "sales", "reason": "New customer interested in enterprise pricing"})
take_message()
Record a message when the requested person/department is unavailable
PARAMETERS

{
            "caller_name": string - Name of the caller,
            "caller_phone": string - Callback number,
            "message": string - The message content,
            "urgency": string - low, medium, or high,
            "for_department": string - Which department the message is for
        }
EXAMPLE CALL

take_message({"caller_name": "John Smith", "caller_phone": "+1-555-123-4567", "message": "Wants to discuss renewal of contract #4521", "urgency": "medium", "for_department": "sales"})
lookup_employee()
Find an employee by name to transfer the call
PARAMETERS

{
            "name": string - Name or partial name of the employee
        }
EXAMPLE CALL

lookup_employee({"name": "Sarah Johnson"})
3. Webhook Handler
Handle tool calls from SIP4AI in your backend.

webhook.js
Copy
app.post('/webhook/receptionist', async (req, res) => {
  const { tool_name, parameters, call_id } = req.body;
  
  switch (tool_name) {
    case 'transfer_call':
      // Transfer to department's hunt group
      const extensions = {
        sales: 'sip:sales@pbx.example.com',
        support: 'sip:support@pbx.example.com',
        billing: 'sip:billing@pbx.example.com',
        hr: 'sip:hr@pbx.example.com'
      };
      await sip4ai.transfer(call_id, extensions[parameters.department]);
      return res.json({ success: true, message: `Transferring to ${parameters.department}` });
      
    case 'take_message':
      // Save to database and notify via Slack/email
      await db.messages.create(parameters);
      await slack.notify(`New message from ${parameters.caller_name}: ${parameters.message}`);
      return res.json({ success: true, message: 'Message recorded' });
      
    case 'lookup_employee':
      const employee = await db.employees.findByName(parameters.name);
      return res.json({ 
        found: !!employee,
        extension: employee?.extension,
        department: employee?.department
      });
  }
});
