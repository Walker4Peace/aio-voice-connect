Background information
The API interface is restricted by the dial permission of the caller.
Make internal call
If the callee is an extension number, and the caller is not allowed to view the
callee (set in the Client Permission on the PBX), then the call would fail and
trigger a (30015) Call Failure Report event.
Make external call
If the callee is an external number, and the caller has no outbound call permission,
then the call would fail and trigger a (30015) Call Failure Report event.
Note:
In this case, you can use the dial_permission parameter to make the call with the
dial permission of other extensions.
Request URL
POST {base_url}/{api_path}/call/dial?access_token={access_token}

Request example

number 5503301.
POST /openapi/v1.0/call/dial?access_token=4aR4RzkFGEfIvGDJVbAd4vEWg6NtoWog
HTTP/1.1

Content-Type: application/json
