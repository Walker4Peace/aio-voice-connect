Changement d'onglet

Pour récupérer ces informations (transcription, données collectées et résultats d'évaluation) directement dans votre application « AIO Voice Connect », vous devez utiliser les webhooks post-appel.

Voici la marche à suivre :

Configurez votre endpoint : Sur votre plateforme « AIO Voice Connect », créez une URL (un endpoint) capable de recevoir des requêtes POST.
Enregistrez l'URL dans ElevenLabs :
Allez dans l'onglet Paramètres de votre agent.
Cherchez la section Webhooks.
Ajoutez votre URL dans le champ dédié aux webhooks post-appel.
Récupérez les données : Une fois l'appel terminé, ElevenLabs enverra automatiquement un payload JSON à votre URL. Vous y trouverez :
La transcription : Dans le champ transcript.
La collecte de données : Dans analysis.data_collection_results_list (vous y verrez vos champs nom_appelant, adresse_livraison, etc.).
L'évaluation des critères : Dans analysis.evaluation_criteria_results_list (les résultats de vos 3 critères).
Sécurisez l'échange : Validez toujours l'en-tête elevenlabs-signature avec votre secret partagé (HMAC) pour vous assurer que les données proviennent bien d'ElevenLabs.
Votre endpoint doit répondre par un code 200 OK pour confirmer la bonne réception. Avez-vous besoin d'un exemple de structure JSON pour ce payload afin de préparer votre développement ?
