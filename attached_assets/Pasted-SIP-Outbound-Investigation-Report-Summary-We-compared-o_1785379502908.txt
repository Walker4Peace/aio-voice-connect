SIP Outbound Investigation Report

Summary

We compared our SIP Agent implementation with the official SIP4AI implementation.

The SIP4AI outbound flow works correctly:

* only one SIP call
* only one ElevenLabs conversation
* AI starts only after the callee answers
* RTP works correctly
* speech is exchanged normally

Our SIP Agent still exhibits an issue where the AI greeting is spoken before the customer actually hears it.

This strongly suggests that our outbound call flow differs from SIP4AI.

Main Suspected Bug

The SIP Agent likely initializes the AI session before the SIP dialog is fully established.

The implementation should delay:

* ElevenLabs websocket creation
* AI session initialization
* greeting generation
* RTP bridge activation

until after the SIP stack receives 200 OK, sends ACK, and the remote RTP endpoint is confirmed.

Using SIP4AI’s outbound implementation as the reference should make it straightforward to identify where our project starts the AI pipeline too early.
