We already receive the ElevenLabs conversation ID in the second call leg.

I now want to complete the ElevenLabs post-call integration.

The goal is that when a call finishes, ElevenLabs automatically updates the existing call history record with the conversation transcript and AI analysis.

Requirements:

1. WEBHOOK

Use our existing endpoint:

POST /api/providers/elevenlabs/post-call

Verify the HMAC signature using the Post-Call Webhook Secret stored in the AI Agent configuration.

Return HTTP 200 immediately after successful processing.

---

2. FIND THE CALL

The webhook contains the ElevenLabs conversation_id.

Find the existing call record by conversation_id.

DO NOT create a new call.

Simply update the existing call.

---

3. STORE THE FOLLOWING FIELDS

Store the raw ElevenLabs payload for debugging.

Also extract and save:

conversation_id

transcript

conversation summary (if available)

analysis

evaluation criteria results

data collection results

Store these as JSON in the database.

Example:

call.transcript

call.analysis_json

call.criteria_results_json

call.data_collection_json

---

4. TRANSCRIPT

Save the complete transcript exactly as received from ElevenLabs.

Do not modify it.

This transcript will be displayed inside the Call Detail modal.

---

5. EVALUATION CRITERIA

Read:

analysis.evaluation_criteria_results_list

Save every criterion.

Each criterion contains something similar to:

- name
- result
- rationale

Example:

✓ Appelant identifié

Result:
true

Reason:
The agent greeted the caller by name and the caller confirmed it.

---

6. DATA COLLECTION

Read:

analysis.data_collection_results_list

Save every extracted field.

Example:

nom_appelant

Yassine

adresse_livraison

Boulevard Maghreb Arabi Numéro huit

confirmation_commande

true

notes_supplementaires

Livraison après 17 heures

Store all fields exactly as received.

---

7. CALL DETAIL MODAL

Keep the current Call Legs section.

After the AI Responded leg, display a new collapsible section named:

Conversation Transcript

This section displays the complete transcript in chronological order.

The transcript box should have:

- max height 400px
- vertical scroll
- preserve paragraphs
- monospace is NOT required

---

8. CALL RESULT

Below the Call Legs section add another card named:

Call Result

Inside this card show:

Evaluation Criteria

Example:

✓ Appelant identifié

Success

The agent greeted the caller by name.

✓ Adresse de livraison confirmée

Success

The address was confirmed during the conversation.

✓ Confirmation de commande

Success

Customer confirmed the order.

Use green/red badges for success/failure.

---

9. EXTRACTED DATA

Inside the Call Result card, below Evaluation Criteria, add:

Collected Data

Display as a clean two-column table.

Example:

Caller Name
Yassine

Delivery Address
Boulevard Maghreb Arabi Numéro huit

Order Confirmed
Yes

Additional Notes
Delivery after 17:00

Only show fields returned by ElevenLabs.

---

10. LOADING

Immediately after a call ends, the modal may open before ElevenLabs sends the webhook.

If transcript or analysis is missing:

Display:

"Waiting for ElevenLabs post-call analysis..."

Automatically refresh the call every 5 seconds until transcript arrives or for a maximum of 60 seconds.

---

11. API

Extend the existing Call Detail API to return:

transcript

analysis

evaluationCriteria

dataCollection

No additional endpoint should be necessary.

---

12. DATABASE

Do not overwrite call metadata.

Simply enrich the existing call with post-call information after the webhook arrives.

The webhook processing should be idempotent.

Receiving the same webhook twice must not duplicate data.
